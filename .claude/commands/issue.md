次の内容を、このリポジトリの GitHub issue として登録する。

内容: $ARGUMENTS

## 手順

1. 内容から、何をしたいかが一目でわかる簡潔なタイトルを付ける（日本語、40 文字程度まで）
   - 頭に種類のプレフィックスを付け、対応するラベルを選ぶ

     | プレフィックス | 種類 | ラベル |
     |---|---|---|
     | `feat:` | 機能追加 | `enhancement` |
     | `fix:` | バグ修正 | `bug` |
     | `docs:` | ドキュメント | `documentation` |
     | `chore:` | 設定・雑務・リファクタ | なし |

   - 例: `feat: 音声読み上げ機能を追加する`
2. 本文を次の見出しで整理する。内容に書かれていないことは推測で埋めず、わからない項目は「なし」とする
   ```
   ## 背景
   なぜ必要か、何がきっかけか

   ## やりたいこと
   実現したいこと

   ## メモ
   関連するファイル、気づいた点、参考情報など
   ```
3. `gh issue create --title "<タイトル>" --body "<本文>" --label "<ラベル>"` で作成する（ラベルなしの場合は `--label` を付けない）

## 守ること

- issue を作るだけで、内容の実装や調査には着手しない
- 作業中のタスクがあれば、issue 作成後そのまま再開する
- 作成後は issue の URL だけを一言で報告する
